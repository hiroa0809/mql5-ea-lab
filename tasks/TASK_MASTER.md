### タスク

**追加の共通フィルタ（2026-07-26 確定）**

- パターン足が **当日の最高値／最安値を更新していること**を必須条件とする（買いシグナル＝当日安値、売りシグナル＝当日高値）。
- **「その時点までの当日高安」で判定する**（日の 00:00 からパターン足まで）。日が終わってからの確定高安を使うと**未来参照＝リペイント**になりバックテストが実運用と乖離するため。
- 実装は `iTime(_Symbol, PERIOD_D1, 0)` で当日開始を取り、そこからパターン足までを `iHighest`/`iLowest` で判定。
- 副作用として日の後半ほど条件が厳しく、朝方ほど成立しやすい非対称性が出る（仕様上の性質として許容）。

- [x] E1: `Include/Signals/PriceAction.mqh`（2026-07-26）— 定番3種を実装。確定足（`shift>=1`）のみ評価しリペイント回避。閾値は ATR 正規化。「当日高安更新」フィルタは `input` で ON/OFF
- [x] E2: 目視確認用インジケータ `Indicators/PriceActionViewer.mq5`（2026-07-26）— 3種とも USDJPY# M15 で目視確認済み

#### 確定したパターン定義（目視確認済み・再導出禁止）

| パターン | 判定 |
|---|---|
| ピンバー | 長ヒゲ ≧ レンジの66%（`InpPinWickRatio`）/ 反対ヒゲ ≦ 15%（`InpPinOppositeRatio`）。実体の色は問わない |
| 包み足 | **①全レンジ（ヒゲ含む）で一本目を完全に包む ②二本目の終値が一本目の高値/安値を超えて終える**。②は**ハードコーディング**（選択式にしない） |
| はらみ足 | 一本目の全レンジ内に二本目が完全に収まる（ヒゲ含む） |

- **実体基準ではなく全レンジ基準**。実体で判定すると見た目と乖離する（当初の実装ミス。前足が極小のとき同値で成立してしまう問題もあった）。同値は「超えた/収まった」と見なさないため**等号を含めない**。
- **はらみ足のみ、当日高安の判定対象を一本目（`shift+1`）に振り替える**。二本目は定義上一本目の内側に収まるため、二本目で判定すると原理的に成立せず常にゼロ件になる。買い＝一本目が当日安値、売り＝一本目が当日高値。
- 当日高安フィルタは検出を**約1/10に絞る**（USDJPY# M15 実測）。**E4 では取引回数もあわせて確認すること**。50回を切る場合その数字は参考程度に留める（サンプル不足で優位性を判断できない）。フィルタは ON/OFF 両方でテストし比較する。

## 運用知見メモ

- **CodeRabbit の再レビューは短時間に連発しない**（無料プランのレビュー回数制限。上限到達で約25分待ちが発生）。指摘はまとめて1回の push で対応する（2026-07-26 PR #1 で遭遇）
- **コンパイル判定は `Result:` 行を読む**。MetaEditor の終了コードは成功／失敗どちらでも同じで当てにならない
- **セッション区切りごとにブランチを main へ統合する**（`fin` ステップ3.5）。統合せず枝を切り続けると、いつか main から切って先祖返りする（過去の事故）
