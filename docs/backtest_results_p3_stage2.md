# P3 第2段階 — スパンモデル側の②③④（学習期間）

> 実施 2026-08-22。手順は `backtest_plan_p3_squeeze.md` §6。
> **結論: ②③④はいずれも「使わない」が最良。現行設定が216通り中2位。**
>
> 数字はすべて `tools/analyze-spanmodel-234.py` の出力。手で書き写した数字は載せない。

## 1. 条件

膠着の設定はユーザー決定の固定値。振ったのはスパンモデル側の②③④とエントリーのきっかけ。

| 項目 | 値 |
|---|---|
| 銘柄 / 期間 | USDJPY# ／ 2018-11-01〜2022-12-31（学習期間） |
| 売買する足 | **15分** |
| 膠着 | **③ケルトナーの内側 / 測る足=4時間 / 期間21 / 倍率1.5** |
| 執行 | **入遅1・決遅1**（ユーザー決定により振らない） |
| ティックの作り方 | 始値のみ（Model=2） |
| ロット | 0.10 固定（1 pip = 100円） |

振った項目:

| 入力の表示 | 選択肢 | 通り |
|---|---|---|
| ②遅行スパンを何と比べるか | 使わない／a 終値を抜く／b 高値安値を抜く／c 雲を抜く／a+c／b+c | 6 |
| ③終値と青スパンの位置関係を条件に入れる | 入れない／入れる | 2 |
| ④長期スパンの傾き | 使わない／1〜5本前と比べる | 6 |
| エントリーのきっかけ | 雲の色が変わったとき／膠着が始まったとき／どちらでも | 3 |

**合計216通り。②③④をすべて「使わない」にした行が現行設定にあたり、この216通りの中に含まれる**（比較相手を別に走らせる必要がない）。

再現: `tools/run-backtest.ps1 -Tag sm_m15 -Period M15 -Optimize -LagMode '0:1:5' -UseClosePos '0:1:1' -SlopeMode '0:1:5' -EntryTrigger '0:1:2' -EntryDelay '1' -ExitDelay '1' -SqueezeUse '3' -SqueezeTF '2' -SqueezePeriod '21' -SqueezeKcMult '1.5' -SqueezeLookback '120' -SqueezeThreshold '10.0' -MacroUse '0'`

> **MT5 が自動アップデートを挟むと、実行スクリプトが実行を見失う。** 起動した端末が更新用プロセスへ引き継いで即終了するため、`WaitForExit` が 0 分で返り「CSV がありません」で失敗する。テストは裏で走っているので、端末ログの `Startup ... successfully initialized from start config` と `automatic testing started` を確認し、CSV の更新時刻で完了を判定する。

## 3. ②③④それぞれの効き方

他をまたいだ中央値。最良の1件では判断しない。

### ②遅行スパンを何と比べるか

| 選択肢 | 合計円 中央値 | 回数 中央値 | 1回pips | 黒字の割合 | 合格の割合 |
|---|---|---|---|---|---|
| **使わない** | **58,165** | 346 | 2.03 | 100% | 22% |
| b 高値安値を抜く | 37,795 | 256 | 1.66 | 100% | 22% |
| a 終値を抜く | 27,785 | 283 | 1.33 | 83% | 22% |
| c 雲を抜く | 24,760 | 264 | 1.35 | 100% | 3% |
| b+c 高安と雲 | 23,745 | 228 | 1.54 | 100% | 6% |
| a+c 終値と雲 | 20,840 | 246 | 1.12 | 100% | 3% |

**使わないのが最良。条件を重ねる（a+c、b+c）ほど下がる。**

### ③終値と青スパンの位置関係

| 選択肢 | 合計円 中央値 | 回数 中央値 | 1回pips | 黒字の割合 | 合格の割合 |

| 入れる | 25,440 | 252 | 1.68 | 98% | 13% |

**ほぼ差がない。** 合計では入れないがわずかに上、1回あたりでは入れるが上。上位20件では入れる9件・入れない11件。

## 5. 数字の限界

- 学習期間のみ。**検証用期間は使っていない**（残り1〜2回）
- 損益はすべてネット。合格ライン相当のネット 3.01 pips は学習期間の往復コスト 0.69 pips を戻した近似
- 標準誤差は出していない（P1 の保留理由と同じ）
- 執行（入遅・決遅）は1・1に固定した。`backtest_plan_p3_squeeze.md` §6 は「②③④と組み合わせると最良の本数が変わりうるのでここでも振る」としており、**そこは確かめていない**
