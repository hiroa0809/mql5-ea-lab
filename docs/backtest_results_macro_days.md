# マクロ反応日での絞り込み — 検証結果

## 1. 何を試したか

別プロジェクト（OLS-MeanReversion_MT5）が「行き過ぎからの回帰」を狙う売買で**建てるのを止める日**として使っている一覧を、向きを逆にして借りた。マクロが荒れている＝回帰が効かない＝順張りには都合がよい、という仮説。

| 項目 | 内容 |
|---|---|
| 銘柄 / 期間 | USDJPY# ／ 2018-11-01 〜 2022-12-31（学習期間） |
| 時間足 | 10分・15分・1時間 |
| ティックの作り方 | 始値のみ（Model=2） |
| 絞り込み | なし / 反応した日だけ / **反応しなかった日だけ（対照）** |
| 日付の一覧 | `docs/suppress_days_r2_report.txt`（73区間・実日数876日・2018-10-11〜2026-04-08） |
| R2 の中身 | 恐怖指数25超 ∨ 恐怖指数が252日で+1.5σ超 ∨ 原油66日で−1.5σ未満 ∨ 信用代理66日で−1.5σ未満 |

**対照（反応しなかった日だけ）を必ず一緒に測る。** これが無いと、成績が動いたときに「マクロが効いた」のか「取引が減っただけ」なのか切り分けられない。

## 2. 結論

**仮説は支持されなかった。採用しない。**

3つの時間足すべてで同じ向きに出た関係は**1つだけ**で、それは仮説と逆だった。

| 引き金 | 10分 | 15分 | 1時間 | |
|---|---|---|---|---|
| **雲の色の変化で入る** | **−0.78** | **−0.82** | **−1.61** | **3つとも悪化** |
| 膠着の開始で入る | −1.40 | +0.16 | +11.24 | 割れている |
| どちらでも | −1.37 | +0.14 | +8.47 | 割れている |

（数字は「反応した日だけ − 絞り込みなし」の 1取引あたり pips 中央値の差。膠着あり2,052通り／1時間足は1,512通り）

割れている2つも、プラス側は15分足の +0.16（往復コスト 1.22 pips に対し誤差）と1時間足の +11.24（下記のとおり信用できない）だけで、10分足は明確にマイナス。

## 3. 膠着なしの場合

執行の遅らせ方4通りをまたいだ中央値。

| 時間足 | | 絞込なし | 反応日のみ | 反応なし日のみ |
|---|---|---|---|---|
| 10分 | 取引数 | 1,578 | 663 | 914 |
| | 1取引 | 0.754 pips | **0.056** | **1.283** |
| 15分 | 取引数 | 1,001 | 392 | 608 |
| | 1取引 | 1.319 pips | **0.473** | **1.865** |
| 1時間 | 取引数 | 255 | 97 | 158 |
| | 1取引 | 4.717 pips | 5.375 | 4.308 |

10分・15分では、反応した日だけにすると1取引あたりが**絞り込みなしの 7% / 36% まで落ちる**。対照（反応しなかった日だけ）が最も良い。

## 4. 1時間足の数字を採らない理由

**反応した日だけの取引数が足りない。**

| 時間足 | 取引数の中央値 | 100回未満のパターン | 1取引pips の四分位範囲 |
|---|---|---|---|
| 10分 | 127 | 37% | −2.44 〜 1.70 |
| 15分 | 93 | 52% | −0.96 〜 3.68 |
| **1時間** | **24** | **88%** | **2.00 〜 19.74** |

1時間足はばらつきの幅が 18 pips で、往復コスト 1.22 pips と桁が違う。**「+11.24 pips 改善」は小標本の産物**であり、1取引あたり 12 pips という水準自体が実現しない値。単体の総当たりでも同じ理由で1時間足は採用しないと結論済み（`backtest_results_spanmodel.md` §2）。

## 5. 型Bについて

前回「時間足をまたいで唯一通用した形」とされた**膠着の開始／③ケルトナー／4時間足**（15分足）では、順序が仮説どおりに揃った。

| マクロ | 取引数 | 1取引pips |
|---|---|---|
| 絞込なし | 77 | 2.293 |
| 反応日のみ | 33.5 | **3.654** |
| 反応なし日のみ | 43.5 | 1.202 |

**ただし取引33回では採用根拠にならない。** 全体像（§2）が否定的である以上、この1点をもって採る理由がない。

## 6. 実装は残す

判定は `Include\Signals\MacroDays.mqh`、EA の入力は「マクロ反応日での絞り込み」。**既定は「使わない」**。総当たりの CSV には `macro_use` 列が残る。

日付の扱いに注意が1つある。元の一覧は UTC のカレンダー日だが、判定は足の時刻（サーバー時刻・UTC+2〜3）で行うため、区間の境目が数時間ずれる。
